Library Book Management System

Project Description

This system helps libraries manage books by allowing users to add, view, and borrow books efficiently.

System Features

  • Add new books
  • View available books
  • Borrow books

Implementation

The system is implemented using Python. To run the program:

  1. Download library_system.py
  2. Open terminal or command prompt
  3. Run: python library_system.py
